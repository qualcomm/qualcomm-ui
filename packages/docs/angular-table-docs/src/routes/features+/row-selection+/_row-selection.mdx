# {frontmatter.title}

::: terms
multi-select, bulk select, toggleSelected, getIsAllRowsSelected, indeterminate
:::

Row selection allows users to select one or more rows in the table using checkboxes. Use `onRowSelectionChange` to track selection state, and `getSelectedRowModel()` to retrieve the currently selected rows. The demo below shows checkboxes in a dedicated column, with a header checkbox for selecting all rows at once.

# {frontmatter.title}

We provide a [Tailwind CSS](https://tailwindcss.com/) plugin which enhances your tailwind theme with QUI colors, fonts, and more.

## Install

Follow the [Tailwind installation instructions](https://tailwindcss.com/docs/installation/using-vite) for your application.

Then install the QUI plugin:

<NpmInstallTabs packages={["@qualcomm-ui/tailwind-plugin"]} />

Once installed, import the plugin where you've configured your tailwind theme:

```css
@import "tailwindcss";
@import "@qualcomm-ui/tailwind-plugin/qui-strict.css";
```

## Strict vs. Non-Strict Mode

The plugin provides two CSS files:

### qui-strict.css (Recommended)

Resets Tailwind's default color, font, radius, and shadow namespaces, forcing you to use only QDS semantic tokens. Arbitrary Tailwind utilities like `bg-red-500` or `shadow-lg` will not work. For QDS-compliant alternatives, refer to our [Theme Colors](/theming/colors) guide.

```css
@import "@qualcomm-ui/tailwind-plugin/qui-strict.css";
```

We recommended strict mode because it enforces design system compliance. This prevents developers from using arbitrary values that may result in poor contrast or conflicting styles.

### qui.css

Use non-strict mode when you need access to Tailwind's full utility set, such as during migration or for prototyping.

```css
@import "@qualcomm-ui/tailwind-plugin/qui.css";
```

## Usage

Avatars can display a user or entity image, initials, or custom content when an image is unavailable. They can also indicate the status of the user or entity.

## Overview

The anatomy of the avatar component is as follows:

- `q-avatar-root`: The main component.
- `q-avatar-image`: (optional) Displays an image as the avatar.
- `q-avatar-content`: (optional) Displays alternative content, such as initials or an icon, and acts as a fallback if the image fails to load.
- `q-avatar-status`: (optional) Shows a status indicator dot.

### Sizes

::: terms

small
medium
large
extra large
:::

Use the [size](./#size) input to set the size of the avatar. The available sizes are `xs`, `sm`, `md` (default), `lg`, and `xl`.

<QdsDemo name="AvatarSizeDemo" />

### Emphasis

::: terms
high contrast
color scheme
:::

When displaying initials or an icon, use the [emphasis](./#emphasis) input to set the avatar's color. Available values are `neutral` (default), `contrast`, and `brand`.

<QdsDemo name="AvatarEmphasisDemo" className="bg-neutral-03" />

### Status

::: terms
presence indicator
online
:::

To indicate the status of the user or entity, use the `q-avatar-status` directive and set its [status](./#status-1) input to one of: `active`, `offline` (default), `away`, or `busy`.

### Data Types

The viewer renders values with type-specific coloring for strings, numbers, booleans, null, undefined, dates, regex, and more.

<QdsDemo name="JsonViewerDataTypesDemo" />

### Root Provider

Use `createJsonViewerState` with `q-json-viewer-root-provider` to control the viewer state externally, such as expanding or collapsing all nodes programmatically.

<QdsDemo name="JsonViewerRootProviderDemo" />

### Complex Types

Maps, Sets, Headers, URLSearchParams, URLs, Errors, and functions are all supported.

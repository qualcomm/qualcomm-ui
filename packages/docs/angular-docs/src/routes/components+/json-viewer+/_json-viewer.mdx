## Examples

### Interactive

Select a `.json` file with [File Input](/components/file-input) to view its contents as a tree. Invalid JSON displays an error. Clear the selected file to reset the viewer.

> This example is intended for smaller JSON files, typically under 100 KB. The `lazyMount` option reduces initial rendering work for larger files by deferring branch content until expansion. Expanding all nodes programmatically renders the entire tree and can reduce responsiveness for large datasets.

<QdsDemo name="JsonViewerInteractiveDemo" />

### Simple

Pass any JavaScript value to `data`. Use `defaultExpandedDepth` to control how many levels are expanded initially.

<QdsDemo name="JsonViewerSimpleDemo" />

### Composite

Apply `q-json-viewer-root` to a containing element to configure the viewer. Apply `q-json-viewer-tree` to a child element to render the data. Use the composite API to render additional content alongside the tree.

<QdsDemo name="JsonViewerCompositeDemo" />

### Data Types

The viewer renders values with type-specific coloring for strings, numbers, booleans, null, undefined, dates, regex, and more.

<QdsDemo name="JsonViewerDataTypesDemo" />

### Controlled Expansion

Use `expandedValue` and `expandedValueChanged` to control expansion. Call `collection().getBranchValues()` to expand all branches, or set `expandedValue` to an empty array to collapse them.

<QdsDemo name="JsonViewerControlledDemo" />

### Complex Types

Maps, Sets, Headers, URLSearchParams, URLs, Errors, and functions are all supported.

<QdsDemo name="JsonViewerComplexTypesDemo" />

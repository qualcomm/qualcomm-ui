## Examples

### Simple

The simple API bundles all subcomponents together into a single directive.

<QdsDemo name="InlineNotificationSimpleDemo" />

### Child Directives

::: terms
slots, override
:::

Provide child directives to customize specific elements while keeping the simple API's default structure.

<QdsDemo name="InlineNotificationChildDirectivesDemo" />

### Composite

::: terms
slots, parts
:::

Build with the composite API for granular control. This API requires you to provide each subcomponent, but gives you full control over the structure.

<QdsDemo name="InlineNotificationCompositeDemo" />

### Emphasis (color)

::: terms
severity, alert level
:::

Control the visual emphasis with different colors: info, success, warning, danger, and neutral. Customize these with the [emphasis](./#emphasis) prop.

<QdsDemo name="InlineNotificationEmphasisDemo" />

### Dismissable

::: terms
closeable, closable
:::

Add dismiss functionality to the simple notification using the [dismissable](./#dismissable-1) prop. Use the `q-inline-notification-close-button` directive when using the composite API.

<QdsDemo name="InlineNotificationDismissableDemo" />

### Action

::: terms
cta, call to action
:::

Include a link or action in notifications using the `q-inline-notification-action` directive.

<QdsDemo name="InlineNotificationActionDemo" />

### Layout

::: terms
horizontal, vertical, orientation
:::

Choose between inline and stacked layouts using the [orientation](./#orientation) property. Stacked layout places the description and action below the content.

<QdsDemo name="InlineNotificationLayoutDemo" />

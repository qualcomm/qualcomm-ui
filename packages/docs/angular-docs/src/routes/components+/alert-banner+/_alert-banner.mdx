### Emphasis

::: terms
severity, notification type, error banner, success banner, alert level
:::

The [emphasis](./#emphasis-1) prop controls the banner's color scheme. The default is `info`. Each emphasis also determines the default icon.

<QdsDemo name="AlertBannerEmphasisDemo" />

### Variant

::: terms
strong banner, subtle banner, banner style, visual weight
:::

The [variant](./#variant-1) prop controls visual prominence. The default `strong` variant uses solid backgrounds for high visibility. The `subtle` variant uses muted backgrounds with borders.

<QdsDemo name="AlertBannerVariantDemo" />

### Dismissable

::: terms
closeable, close banner, remove banner, hide banner
:::

The banner is a controlled component. Set [dismissable](./#dismissable-1) to render a close button, then handle visibility state via the [closed](./#closed) output. With the composite API, use `q-alert-banner-close-button`.

<QdsDemo name="AlertBannerDismissableDemo" />

### Action

::: terms
banner button, banner cta, call to action
:::

The `q-alert-banner-button` was added in [v2.6.0](https://github.com/qualcomm/qualcomm-ui/blob/main/packages/frameworks/angular/CHANGELOG.md#260) and should be used instead of the `q-alert-banner-action` directive.

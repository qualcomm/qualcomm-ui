### Emphasis

::: meta
keywords: [severity, notification type, error banner, success banner, alert level]
:::

The [emphasis](./#emphasis) prop controls the banner's color scheme. The default is `info`. Each emphasis also determines the default icon.

<QdsDemo name="AlertBannerEmphasisDemo" />

### Variant

::: meta
keywords: [strong banner, subtle banner, banner style, visual weight]
:::

The [variant](./#variant) prop controls visual prominence. The default `strong` variant uses solid backgrounds for high visibility. The `subtle` variant uses muted backgrounds with borders.

<QdsDemo name="AlertBannerVariantDemo" />

### Dismissable

::: meta
keywords: [closeable, close banner, remove banner, hide banner]
:::

The banner is a controlled component. Set [dismissable](./#dismissable) to render a close button, then handle visibility state via the [closed](./#closed) output. With the composite API, use `q-alert-banner-close-button`.

<QdsDemo name="AlertBannerDismissableDemo" />

### Action

::: meta
keywords: [banner button, banner cta, call to action]
:::

Pass a button using the `q-alert-banner-action` directive. Use `size="sm"` with `emphasis="white-persistent"` for strong banners, or `emphasis="neutral"` for subtle banners.

<QdsDemo name="AlertBannerActionDemo" />

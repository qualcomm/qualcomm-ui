## Examples

### Simple

Use the simple API to create a switch group using minimal markup.

If you omit the [label](./#label), you should provide an `aria-label` to keep your group accessible.

<QdsDemo name="SwitchGroupSimpleDemo" />

### Composite

The composite API exposes `FieldGroup` directives for granular control over the group structure.

<QdsDemo name="SwitchGroupCompositeDemo" />

### Size

::: terms
small
medium
large
:::

The [size](./#size) input controls the size of child switches. Available sizes are `sm`, `md` (default), and `lg`.

<QdsDemo name="SwitchGroupSizeDemo" />

### Orientation

::: terms
vertical
horizontal
row
column
:::

Use the [orientation](./#orientation) input to control the layout direction of the group. Options include:

- `vertical`: switches are laid out in a column (default).
- `horizontal`: switches are laid out in a row.

<QdsDemo name="SwitchGroupOrientationDemo" />

### Indented

Set [indented](./#indented) to add padding at the start of the group.

<QdsDemo name="SwitchGroupIndentedDemo" />

### Hint

::: terms
helper text
description
:::

Use [hint](./#hint) to add additional guidance or context to the user below the group.

<QdsDemo name="SwitchGroupHintDemo" />

### Error Text

::: terms
validation
invalid
:::

Set [invalid](./#invalid) and [errorText](./#errorText) to display validation errors. The error text replaces the hint when present.

<QdsDemo name="SwitchGroupErrorDemo" />

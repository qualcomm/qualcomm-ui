## Examples

### Horizontal

::: terms
keyboard navigation
:::

The default [orientation](./#orientation) is horizontal. The left and right arrow keys can be used to navigate between tabs.

### Vertical

::: terms
stacked tabs

### Icons and variants

Tabs support start and end icons. Customize the variant with the [iconVariant](./#iconVariant) prop. Use the [variant](./#variant) prop to change the appearance of the tab.

<QdsDemo wrapperProps={{className: "bg-neutral-02"}} name="TabsIconsDemo" />

### Controlled Value

The tab's active value can be controlled via the [value](./#value), [valueChanged](./#valueChanged), and [defaultValue](./#defaultValue) properties. These props follow our [controlled state](/patterns/controlled-state) pattern.

<QdsDemo name="TabsControlledValueDemo" />

#### tabsContext

Used to access the tabs API from the template.

```angular2html
<div q-tabs-root>
  <!-- type-aware context for the tabs API -->
  <ng-container *tabsContext="let tabsApi">
    <button (click)="tabsApi.setValue('...')"></button>
  </ng-container>
</div>
```

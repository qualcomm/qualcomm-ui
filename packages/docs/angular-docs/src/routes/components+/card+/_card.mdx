## Examples

### Showcase

All card parts are optional. Combine them to fit the content you need to display.

<QdsDemo name="CardShowcaseDemo" />

### Variants

::: terms
outline, outline-elevated, elevated, style, appearance
:::

The [variant](./#variant) input controls border and shadow styles.

<QdsDemo name="CardVariantsDemo" />

### Actions

Two types of actions are supported in cards: `q-card-button` and `q-card-link`.

<QdsDemo name="CardActionsDemo" />

### Interactive

::: terms
interactive, hover, press, clickable, selectable
:::

Set [interactive](./#interactive-1) on `q-card` to enable hover and pressed visual states on the content area. Place the directive on a `<button>` element so screen readers know that the element is interactive.

> [!warning]
> Interactive cards must not contain buttons, links, or input fields. Nesting interactive elements produces invalid HTML and breaks assistive technology.

<QdsDemo name="CardInteractiveDemo" />

### Media

::: terms
media, image, photo, thumbnail, cover
:::

Use `q-card-media` to display an image or other visual content at the top of the card.

<QdsDemo name="CardMediaDemo" />

### Badge

Use the `q-card-badge` directive to position a badge within the card.

<QdsDemo name="CardBadgeDemo" />

### Alignment

::: terms
alignment, start, center, centered, justify
:::

Set [alignment](./#alignment-1) on `q-card` to control horizontal positioning of heading and footer content. Defaults to `start`.

<QdsDemo name="CardAlignmentDemo" />

### Sizes

::: terms
size, small, medium, large, spacing, typography, scale
:::

Cards support `sm`, `md`, and `lg` sizes that control internal spacing and typography.

<QdsDemo name="CardSizesDemo" />

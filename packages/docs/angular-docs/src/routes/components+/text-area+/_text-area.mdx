## Examples

### Simple

::: terms
resizable input, expandable input
:::

The simple `<q-text-area>` bundles all subcomponents together into a single component.

<QdsDemo name="TextAreaSimpleDemo" />

### Composite

Build with the composite API for granular control. This API requires you to provide each subcomponent, but gives you full control over the structure and layout.

<QdsDemo name="TextAreaCompositeDemo" />

### Counter

Display a character count using [counter](./#counter-1) or by setting a [maxLength](./#maxLength).

By default, the counter displays:

- `count/max` when `maxLength` is set
- `count` when only `counter` is used

Use the `q-text-area-counter` directive with a [display](./#display) function to customize the format.

<QdsDemo name="TextAreaCounterDemo" />

### Sizes

::: terms
small, medium, large
:::

Customize size using [size](./#size). The default size is `md`.

<QdsDemo name="TextAreaSizesDemo" />

### Value Changed

Listen to changes with the [valueChanged](./#valueChanged) output.

<QdsDemo expanded name="TextAreaValueChangedDemo" />

### Error Text and Indicator

::: terms
validation error, form validation, error message display
:::

Error messages are displayed using two inputs:

- [invalid](./#invalid)
- [errorText](./#errorText) (or the `q-text-area-error-text` directive when using the composite API)

The error text and indicator will only render when [invalid](./#invalid) is true.

<QdsDemo name="TextAreaErrorTextDemo" />

## Forms

Control and validate the input value using Angular form control bindings.

### Template Forms

::: terms
FormsModule, two-way binding
:::

When using template-driven forms with `ngModel`, perform validation manually in your component and pass the result to [invalid](./#invalid).

<QdsDemo expanded name="TextAreaTemplateFormsDemo" />

#### States

::: terms
disabled state, read-only state, required field, invalid state, form states
:::

When using template forms, [disabled](./#disabled), [readOnly](./#readOnly), and [invalid](./#invalid) govern the interactive state of the control.

<QdsDemo name="TextAreaStatesDemo" />

#### Required

When using template forms, pass [required](./#required-1) to apply the [RequiredValidator](https://angular.dev/api/forms/RequiredValidator) to the form control.

<QdsDemo name="TextAreaRequiredTemplateFormsDemo" />

### Reactive Forms

::: terms
FormControl, FormGroup, ReactiveFormsModule
:::

Use Reactive Forms for better control of form state and validation.

<QdsDemo expanded name="TextAreaReactiveFormsDemo" />

#### State Guidelines

::: terms
form control state, Validators
:::

The [disabled](./#disabled), [invalid](./#invalid), and [required](./#required-1) inputs have no effect when using Reactive Forms. Use the equivalent Reactive Form bindings instead:

<QdsDemo name="TextAreaReactiveFormStatesDemo" />

### Composite API & Forms

When using the composite API with Angular Forms, always apply form control bindings to the `q-text-area-root` directive.

<QdsDemo name="TextAreaCompositeFormsDemo" />

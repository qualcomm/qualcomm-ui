## Examples

### Variants

::: terms
solid button
bordered button
transparent button
:::

Buttons come in three variants: fill, outline, and ghost. Customize these with the [variant](./#variant) property.

<QdsDemo name="ButtonStylesDemo" />

### Emphasis

::: terms
destructive button
delete button
:::

Buttons can have different [emphasis](./#emphasis) which affects the color of the button.

<QdsDemo name="ButtonEmphasisDemo" />

### Sizes and Icons

::: terms
small
medium
large
:::

Customize size using the [size](./#size) property. QUI buttons come with built-in support for [lucide-react](https://lucide.dev) icons.

<QdsDemo name="ButtonSizesDemo" />

### Compact Density

::: terms
condensed button
slim button
tight button
:::

Use the [density](./#density) property to reduce the padding and height of the button. The options are `default` and `compact`.

<QdsDemo name="ButtonDensityDemo" />

### Variant Combinations

::: terms
button grid
button matrix
all button styles
:::

This grid shows all button combinations across variants and emphasis levels. The bottom row demonstrates the disabled state, which grays out the button regardless of variant or emphasis.

<QdsDemo name="ButtonVariantsDemo" />

### Contrast Colors

::: terms
high contrast button
button on dark background
inverted button
:::

Use `white-persistent` for buttons on dark backgrounds and `black-persistent` for buttons on light backgrounds. These emphasis values maintain consistent contrast regardless of the active theme.

<QdsDemo name="ButtonContrastDemo" />

### Inverse Contrast

To flip contrast against the active theme, set [emphasis](./#emphasis) to `inverse`.

<QdsDemo name="ButtonInverseDemo" />

### Menu Button

::: terms
menu trigger, dropdown button, icon menu button
:::

For a button that opens a dropdown, use [`q-menu-button`](/components/menu#menu-button) for a labeled trigger or [`q-menu-icon-button`](/components/menu#menu-button) for an icon-only trigger.

### Split Button

::: terms
split action, dropdown button, secondary actions
:::

For a button that pairs a primary action with a dropdown of related actions, use [`q-menu-split-button`](/components/menu#split-button).

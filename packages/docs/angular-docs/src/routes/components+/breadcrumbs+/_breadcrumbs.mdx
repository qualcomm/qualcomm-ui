## Overview

::: terms
a11y, WCAG, site hierarchy, wayfinding, location indicator
:::

- The root element should be labeled with `aria-label="Breadcrumbs"` to indicate that it's a breadcrumb navigation.
- The first breadcrumb item is always the root item, and is typically reserved for the home page or base route of your application.
- The last breadcrumb item is always the active item.
- The last breadcrumb item should always be annotated with the [`aria-current`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-current)`="page"` attribute.

## Examples

### Links

::: terms
polymorphic
:::

Each item renders an `<a>` by default. Without an explicit `href` or `routerLink`, the anchor links to the current page. For navigable items, provide an explicit [`<a q-breadcrumb-item-trigger>`](./#q-breadcrumb-item-trigger) with `href` or `routerLink`.

<QdsDemo name="BreadcrumbsLinksDemo" />

### Items

::: terms
data-driven, items array, programmatic
:::

To render a collection of breadcrumbs from data, pass an [items](./#items-1) array to `q-breadcrumbs-list`. Each item can specify a [link](./#link) string or path array for `routerLink` navigation, or an [href](./#href) string for plain anchor links.

<QdsDemo name="BreadcrumbsItemsDemo" />

### Emphasis (color)

::: terms
neutral, muted, subdued
:::

Use the [emphasis](./#emphasis) input to change the color of the breadcrumbs.

<QdsDemo name="BreadcrumbsEmphasisDemo" />

### Sizes

::: terms
small, medium, large
:::

Three sizes are available via the [size](./#size) input: `sm`, `md`, and `lg`. The default size is `md`.

<QdsDemo name="BreadcrumbsSizesDemo" />

### Disabled Item

::: terms
inactive, non-clickable
:::

Use the [disabled](./#disabled) input to disable a breadcrumb item.

<QdsDemo name="BreadcrumbsDisabledDemo" />

### Overflow

::: terms
overflow, collapsed, ellipsis, truncated
:::

Use the `q-breadcrumb-overflow-item` component to collapse intermediate breadcrumb items into a dropdown menu. The overflow trigger displays an ellipsis by default. Use the [icon](./#icon-1) input to add an icon, or provide your own trigger via `q-breadcrumb-overflow-trigger`.

<QdsDemo name="BreadcrumbsOverflowDemo" />

### Max items

::: terms
overflow, collapsed, ellipsis, truncated, max items, auto collapse
:::

When using the [items](./#items) input, add [maxItems](./#maxItems) to automatically collapse intermediate items into a dropdown menu when the total count exceeds the threshold. The first and last items remain visible by default. Use [startItems](./#startItems) and [endItems](./#endItems) to control how many items stay visible at each end.

<QdsDemo name="BreadcrumbsMaxItemsDemo" />

### Tooltip

::: terms
tooltip, hover hint, title, description
:::

To provide additional context on hover, add a tooltip to a breadcrumb item by wrapping its trigger with a [Tooltip](/components/tooltip) and apply `q-tooltip-trigger` to it.

<QdsDemo name="BreadcrumbsTooltipDemo" />

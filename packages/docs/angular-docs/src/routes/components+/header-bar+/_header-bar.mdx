## Examples

> [!tip/Responsive Design]
> These examples use Tailwind [container queries](https://tailwindcss.com/docs/responsive-design#container-queries) for mobile-first responsiveness. Tailwind is installed on our documentation sites only, and is not required to use any of our components.

### Basic Usage

::: terms
responsive, icon button, user avatar
:::

A typical header bar includes a logo, application title, nav items, and an action bar.

<QdsDemo name="HeaderBarShowcaseDemo" />

### Sizes

::: terms
small, large, compact
:::

The header bar has two sizes: `sm` (default) and `lg`. The [size](./#size) input governs padding, element spacing, and height.

<QdsDemo name="HeaderBarSizesDemo" />

### Surfaces

::: terms
theme, color scheme
:::

Use the [surface](./#surface) input to set the background color. Available options are `primary` (default) and `secondary`.

<QdsDemo name="HeaderBarSurfacesDemo" />

### Padding

::: terms
spacing, horizontal space
:::

Set the [padding](./#padding-1) input to `large` to increase horizontal padding.

<QdsDemo name="HeaderBarPaddingDemo" />

### Menu Items

::: terms
nav menu
:::

Render a menu nav item with the [q-header-bar-menu-item](./#q-header-bar-menu-item) and q-menu-trigger directives. This component must be wrapped in a q-menu.

<QdsDemo name="HeaderBarMenuItemDemo" />

## Overview

::: terms
feather
feather icons
lucide
:::

QUI components use icons from [Lucide](https://lucide.dev/), an open-source fork of Feather Icons.

Many components like the [Button](/components/button), [Icon Button](/components/icon-button), and [Text Input](/components/text-input) have built-in support for Lucide Icons.

## Examples

### Provider

::: terms
register icons

provide icons

Use the `provideIcons` utility function to register icons. Provided icons are matched by their string name.

Size can be customized using the [size](./#size) input. There are five available values: `xs`, `sm`, `md`, `lg`, `xl`. Should you need more control over the rendered size, supply a number instead which will be converted to pixels.

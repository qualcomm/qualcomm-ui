## Examples

### Icons

::: terms
leading icon
trailing icon
prefix
suffix
:::

Icons are supplied using the [startIcon](./#startIcon) and [endIcon](./#endIcon) properties.

<QdsDemo name="TagIconsDemo" />

### Variants

::: terms
clickable
removable
closable
:::

Choose from three [variants](./#variant): `link`, `selectable` and `dismissable`.

The `link` and `selectable` variants are interactive and should use a `<button>` element.
The `dismissable` variant and tags without a variant are non-interactive and should use a `<span>` element.

<QdsDemo name="TagVariantsDemo" />

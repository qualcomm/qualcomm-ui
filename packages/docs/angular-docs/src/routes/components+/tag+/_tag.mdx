### Variants

::: terms
clickable, removable, closable, chip, pill, filter, toggle, anchor, hyperlink, navigation, active, current
:::

A tag renders as one of four types:

- **read-only** (default) renders static metadata. Use a `<span>`.
- **dismissable** adds a close button. Use a `<span>`, set [variant](./#variant) to `dismissable` and pair it with the dismiss output.
- **selectable** renders as a toggle button. Use a `<button>` and set [variant](./#variant) to `selectable`.
- **link** renders the tag as an anchor. Use an `<a q-tag>` host with `routerLink` or `href`. Set [`aria-current`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-current) on the active `<a q-tag>` host for accessibility. The optional [active](./#active) input applies the current-item styling.

### Controlled State

::: terms
signal, state management, two-way binding
:::

Set the initial value using the [defaultSelected](./#defaultSelected) input, or use the [selected](./#selected) input together with the [selectedChange](./#selectedChange) output to control the value manually. The pair supports `[(selected)]` two-way binding. Only applicable when [variant](./#variant) is `selectable`.

# {frontmatter.title}

VS Code supplies the interface and editor fonts. The library provides typography presets through CSS variables and Tailwind utilities, using the CSS `font` shorthand.

Follow [Installation](/installation) for library setup and [Tailwind setup](/setup/vite#import-the-css) for the optional adapter.

## Example

<TypographyDemo />

Change **Base font size (px)** to preview how the heading and body styles scale.

> [!tip/Uncolored by default]
> Typography styles inherit text color. Pair them with a class from [Colors](/theming/colors#text) when a specific color is needed.

## Typography scale

Interface sizes scale with `--vscode-font-size`. The tables update with the preview’s base font size; sizes are rounded to two decimal places.

### Heading

Use heading styles for page and section titles.

| Tailwind class | CSS variable | Size at <TypographySize size={13} /> base | Weight |
| --- | --- | --- | --- |

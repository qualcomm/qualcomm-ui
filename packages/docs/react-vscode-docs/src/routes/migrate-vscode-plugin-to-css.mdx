# {frontmatter.title}

Replace `vscodePlugin` from `@qualcomm-ui/tailwind-plugin/vscode` with `@qualcomm-ui/tailwind-plugin/vscode.css`. Update utility names and verify typography, shadows, and opacity in your VS Code webview.

The JavaScript entrypoint has been removed. The CSS adapter supplies theme values through `@theme inline` and typography, shadow, opacity, and semantic text utilities through `@utility`.

## Migration

::: steps h3

### Install the packages

Run the installation commands from your application's directory. Install React VS Code and its dependencies:

<NpmInstallTabs
  packages={[
    "@qualcomm-ui/react-vscode",
    "@qualcomm-ui/react-core",
    "@qualcomm-ui/core",
    "@qualcomm-ui/vscode-core",
    "@qualcomm-ui/dom",
    "@qualcomm-ui/utils",
  ]}
/>

Install or update Tailwind and the adapter as development dependencies:

<NpmInstallTabs
  dev
  packages={["tailwindcss", "@qualcomm-ui/tailwind-plugin"]}
/>

Follow [Vite setup](/setup/vite) for Tailwind build integration.

### Remove plugin registration

Remove the `vscodePlugin` import and its entry in `tailwind.config.ts`. Keep unrelated plugins and custom configuration.

The previous `tailwind.config.ts` loads the removed JavaScript API:

```ts
import {vscodePlugin} from "@qualcomm-ui/tailwind-plugin/vscode"

export default {
  plugins: [vscodePlugin],
}
```

### Import the CSS adapter

Import the adapter and foundation stylesheet in your application's base CSS file:

```css
@import "tailwindcss";
@import "@qualcomm-ui/tailwind-plugin/vscode.css";
@import "@qualcomm-ui/react-vscode/styles.css" layer(components);
```

Keep the base CSS file imported by your application entrypoint.

### Configure the application container

Apply `qui-vscode` to the application container in `src/App.tsx`. It defines the shared token variables and applies the host font and default text color:

```tsx
export default function App() {
  return (
    <main className="qui-vscode">
      <h1 className="font-heading-xxl text-normal">Build configuration</h1>
      <p className="font-body-md text-muted">Output directory: dist</p>
    </main>
  )
}
```

::: /steps

## Update opacity bindings

| JavaScript plugin utility | CSS adapter utility |
| --- | --- |
| `opacity-editorUnnecessaryCode-opacity` | `opacity-editor-unnecessary-code` |
| `opacity-minimap-foregroundOpacity` | `opacity-minimap-foreground` |

These utilities default to `1` (fully opaque). The binding is optional: use a standard utility such as `opacity-50` for fixed opacity, or call `bindVscodeOpacity` on the container to make opacity follow the VS Code theme:

```tsx
import {bindVscodeOpacity} from "@qualcomm-ui/vscode-core/opacity"

function opacityRef(element: HTMLDivElement | null) {
  if (element) {
    return bindVscodeOpacity(element)
  }
}

export function UnusedCode() {
  return (
    <div className="qui-vscode" ref={opacityRef}>
      <code className="opacity-editor-unnecessary-code">
        {'import unusedLogger from "./logger"'}
      </code>
    </div>
  )
}
```

See [Opacity](/theming/colors#opacity) for a comparison with and without the binding.

# {frontmatter.title}

QUI Docs is a toolkit for building documentation websites. You write your content in [MDX](https://mdxjs.com/) or Markdown, and QUI Docs handles the rendering.

## Overview

Its styling follows the Qualcomm Design System (QDS) and complies with Qualcomm's branding guidelines. It also prepares your documentation for use by AI assistants, so they can answer questions using your content. The goal is to help teams focus on their content while giving readers a consistent, easy-to-navigate site.

## Quick Start

We recommend you get started with our preconfigured template:

- [React Router (Framework Mode)](https://github.com/qualcomm/qualcomm-ui-templates/tree/main/templates/react-qui-docs)

Refer to our [page authoring guide](/pages) to start documenting.

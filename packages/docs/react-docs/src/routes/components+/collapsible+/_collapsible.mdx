## Examples

### Showcase

::: terms
uncontrolled, toggle visibility, show hide content
:::

Basic collapsible component with a trigger button that expands and collapses content. The trigger uses the [render](./#render) prop to render as another component like our [Button](/components/button).

### Controlled State

::: terms
external state management, useState
:::

Control the collapsible's open/closed state using the [open](./#open) and [onOpenChange](./#onOpenChange) props. This example demonstrates programmatic control with a close button inside the content.

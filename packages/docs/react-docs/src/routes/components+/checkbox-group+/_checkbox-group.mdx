## Examples

### Simple

Use the simple API to create a checkbox group using minimal markup.

If you omit the [label](./#label), you should provide an `aria-label` prop to keep your group accessible.

  name="CheckboxGroupCompositeDemo"

### Size

::: terms
small
medium
large
:::

The [size](./#size-1) prop controls the size of child checkboxes. Available sizes are `sm`, `md` (default), and `lg`.

<Demo name="CheckboxGroupSizeDemo" component={demos.CheckboxGroupSizeDemo} />

### Orientation

::: terms
vertical
horizontal
row
column
:::

Use the [orientation](./#orientation-1) prop to control the layout direction of the group. Options include:

- `vertical`: checkboxes are laid out in a column (default).
- `horizontal`: checkboxes are laid out in a row.

<Demo
  name="CheckboxGroupOrientationDemo"
  component={demos.CheckboxGroupOrientationDemo}
/>

### Indented

Set [indented](./#indented-1) to add padding at the start of the group.

<Demo
  name="CheckboxGroupIndentedDemo"
  component={demos.CheckboxGroupIndentedDemo}
/>

### Hint

::: terms
helper text
description
:::

Use [hint](./#hint-1) to add additional guidance or context to the user below the group.

<Demo name="CheckboxGroupHintDemo" component={demos.CheckboxGroupHintDemo} />

### Error Text

::: terms
validation
invalid
:::

Set [invalid](./#invalid) and [errorText](./#errorText) to display validation errors. The error text replaces the hint when present.

<Demo name="CheckboxGroupErrorDemo" component={demos.CheckboxGroupErrorDemo} />

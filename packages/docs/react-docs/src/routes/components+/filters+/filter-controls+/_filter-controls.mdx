## Overview

Each filter is a control built on one of our existing components. Render it inside a `FilterPanel.Filter` of a [Filter Panel](../filter-panel.mdx), or inside a `FilterProvider` under a `FilterSetProvider` to use it without a panel.

- `CheckboxGroupFilter`: `string[]`. Pick any number of options.
- `CheckboxTreeFilter`: `string[]`. Pick leaves from a hierarchy. Only leaf values are stored.
- `ComboboxFilter`: `string[]`. Search and pick from a long option list.
- `DateFilter`: `{preset: string} | {range: [string | null, string | null]}`. Pick a date range or a preset. Dates are ISO 8601 strings, and `null` leaves a side open.
- `RadioGroupFilter`: `string[]`. Pick one option. The value is a one-item array.
- `SelectFilter`: `string[]`. Pick from a short option list in a dropdown.
- `SliderFilter`: `[number | null, number | null]`. Pick a numeric range. `null` leaves a side open.
- `TextInputFilter`: `string`. Enter free text.

List and tree filters render the items of the filter's collection, which comes from its definition or the panel's `getFilterCollection`. A filter without a collection shows no options. See [Loading Options](../filter-panel.mdx#loading-options).

Each section below documents only the props specific to that filter. The rest are forwarded to the underlying component.

::: terms

:::

Selects leaves from a hierarchy. Checking a branch checks all of its leaves, and only leaf values are stored. The nodes come from the filter's [TreeCollection](/components/tree#tree-collection), set on `treeFilter`.

## Date Filter

::: terms
date range, presets, last 7 days, calendar
:::

Selects a date range, or one of the definition's presets. Ranges are stored as ISO 8601 dates.

<Demo name="DateFilterDemo" component={demos.DateFilterDemo} />

Presets are listed on the definition. A preset whose value is one of the [date picker's presets](../../date-picker+/_date-picker.mdx#presets), like `"last7Days"`, doesn't need a `range`. Any other preset supplies its own.

```tsx
dateFilter({
  label: "Submitted",
  presets: [
    {label: "Last 7 days", value: "last7Days"},
    {
      label: "Since release",
      range: () => ["2026-09-01", null],
      value: "release",
    },
  ],
})
```

A selected preset is stored as `{preset: "last7Days"}`, not as dates, so it stays relative to the current day. Use `resolveDateFilterPreset` to turn it into a range when you need one:

```tsx
import {resolveDateFilterPreset} from "@qualcomm-ui/core/filters"

const [start, end] = resolveDateFilterPreset(preset)
```

Week presets depend on the locale, and every preset depends on the time zone. Both default to the user's, and can be passed as options.

<TypeDocProps
  name="DateFilterProps"
  pick={["anyLabel", "customRange", "customRangeLabel"]}
/>

Remaining props are forwarded to [DatePicker](../../date-picker+/_date-picker.mdx).

## Slider Filter

::: terms
slider, numeric range, min max
:::

Selects a numeric range with a two-thumb slider. A thumb left at its bound is stored as `null`, which leaves that side open. The value is written when a thumb is released.

The bounds come from the definition's `min` and `max`. Use `formatValue` on the definition to format the values in summaries.

<Demo name="SliderFilterDemo" component={demos.SliderFilterDemo} />

The slider filter has no props of its own. Remaining props are forwarded to [Slider](/components/slider).

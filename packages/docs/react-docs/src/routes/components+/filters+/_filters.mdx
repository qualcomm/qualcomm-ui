## Overview

Each filter renders a collapsible section in a [Filter Panel](/components/filter-panel), with a control built on one of our existing components. Pass the filter's definition to its [filter](./#filter) prop.

- `CheckboxFilter`: pick any number of options. Selection: `string[]`.
- `CheckboxTreeFilter`: pick leaves from a hierarchy. Selection: the checked leaf values as `string[]`.
- `ComboboxFilter`: search and pick from a long option list. Selection: `string[]`.
- `DateFilter`: pick a date range or a preset. Selection: `{range: [start, end]}` or `{preset}`.
- `RadioFilter`: pick one option. Selection: a one-item `string[]`.
- `RangeFilter`: pick a numeric range. Selection: `[min, max]`, with `null` for an open side.
- `SelectFilter`: pick from a short option list in a dropdown. Selection: `string[]`.
- `TextFilter`: enter free text. Selection: a `string`.

Every filter accepts the [section props](./#section-props). Each section below documents only the props specific to that filter. The rest are forwarded to the underlying component.

## Date Filter

::: terms
date range, presets, last 7 days, calendar
:::

Selects a date range, or one of the definition's presets. Ranges are stored as ISO 8601 dates.

<Demo name="DateFilterDemo" component={demos.DateFilterDemo} />

Presets are listed on the definition. A preset whose value is one of the [date picker's presets](/components/date-picker#presets-1), like `"last7Days"`, doesn't need a `range`. Any other preset supplies its own.

```tsx
dateFilter({
  label: "Submitted",
  presets: [
    {label: "Last 7 days", value: "last7Days"},
    {
      label: "Since release",
      range: () => ["2026-09-01", null],
      value: "release",
    },
  ],
})
```

A selected preset is stored as `{preset: "last7Days"}`, not as dates, so it stays relative to the current day. Use `resolveDateFilterPreset` to turn it into a range when you need one:

```tsx
import {resolveDateFilterPreset} from "@qualcomm-ui/core/filters"

const [start, end] = resolveDateFilterPreset(preset)
```

Week presets depend on the locale, and every preset depends on the time zone. Both default to the user's, and can be passed as options.

<TypeDocProps
  name="DateFilterProps"
  pick={["anyLabel", "customRange", "customRangeLabel"]}
/>

Remaining props are forwarded to [DatePicker](/components/date-picker).

## Range Filter

::: terms
slider, numeric range, min max
:::

Selects a numeric range with a two-thumb slider. A thumb left at its bound is stored as `null`, which leaves that side open. The value is written when a thumb is released.

The bounds come from the definition's `min` and `max`. Use `formatValue` on the definition to format the values in summaries.

<Demo name="RangeFilterDemo" component={demos.RangeFilterDemo} />

The range filter has no props of its own. Remaining props are forwarded to [Slider](/components/slider).

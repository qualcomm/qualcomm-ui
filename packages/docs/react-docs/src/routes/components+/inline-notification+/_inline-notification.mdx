### Simple

Basic inline notification using the simple API with heading and description.

  name="InlineNotificationSimpleDemo"

### Composite

::: terms
compound component, slots, parts
:::

Use the composite API with individual components for more granular control.

<Demo
  name="InlineNotificationCompositeDemo"
  component={demos.InlineNotificationCompositeDemo}
/>

### Emphasis (color)

::: terms
severity, alert level
:::

Control the visual emphasis with different colors: info, success, warning, danger, and neutral. Customize these with the [emphasis](./#emphasis) prop.

<Demo
  name="InlineNotificationEmphasisDemo"
  component={demos.InlineNotificationEmphasisDemo}
/>

### Dismissable

::: terms
closeable, closable
:::

Add dismiss functionality to the simple notification using the [dismissable](./#dismissable) prop. Use the `<InlineNotification.CloseButton />` component when using the composite API.

<Demo
  name="InlineNotificationDismissableDemo"
  component={demos.InlineNotificationDismissableDemo}
/>

### Action

::: terms
cta, call to action
:::

Include action links in notifications using the [action](./#action) property or the `<InlineNotification.Action>` component via the composite API.

<Demo
  name="InlineNotificationActionDemo"
  component={demos.InlineNotificationActionDemo}
/>

### Layout

::: terms
horizontal, vertical, orientation
:::

Choose between inline and stacked layouts using the [orientation](./#orientation) property. Stacked layout places the description and action below the content.

<Demo
  name="InlineNotificationLayoutDemo"
  component={demos.InlineNotificationLayoutDemo}
/>

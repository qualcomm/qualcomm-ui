## Examples

### Showcase

All card parts are optional. Combine them to fit the content you need to display.

<Demo name="CardShowcaseDemo" component={demos.CardShowcaseDemo} />

### Variants

::: terms
outline, outline-elevated, elevated, style, appearance
:::

The [variant](./#variant) prop controls border and shadow styles.

<Demo name="CardVariantsDemo" component={demos.CardVariantsDemo} />

### Actions

Two types of actions are supported in cards: `Card.Button` and `Card.Link`.

<Demo component={demos.CardActionsDemo} name="CardActionsDemo" />

### Interactive

::: terms
interactive, hover, press, clickable, selectable
:::

Set [interactive](./#interactive-1) on `Card.Root` to enable hover and pressed visual states on the content area. Use the [render](./#render) prop to make the root element to a `<button>` so screen readers know that the element is interactive.

> [!warning]
> Interactive cards must not contain buttons, links, or input fields. React will yell at you if you nest interactive elements. Install the [QUI React ESLint Plugin](/eslint#plugin) to enforce this in your project.

<Demo name="CardInteractiveDemo" component={demos.CardInteractiveDemo} />

### Media

::: terms
media, image, photo, thumbnail, cover
:::

Use `Card.Media` to display an image or other visual content at the top of the card.

<Demo name="CardMediaDemo" component={demos.CardMediaDemo} />

### Badge

Use `Card.Badge` to place a badge within the card.

<Demo name="CardBadgeDemo" component={demos.CardBadgeDemo} />

### Alignment

::: terms
alignment, start, center, centered, justify
:::

Set [alignment](./#alignment-1) on `Card.Root` to control horizontal positioning of heading and footer content. Defaults to `start`.

<Demo name="CardAlignmentDemo" component={demos.CardAlignmentDemo} />

### Sizes

::: terms
size, small, medium, large, spacing, typography, scale
:::

Cards support `sm`, `md`, and `lg` sizes that control internal spacing and typography.

<Demo name="CardSizesDemo" component={demos.CardSizesDemo} />

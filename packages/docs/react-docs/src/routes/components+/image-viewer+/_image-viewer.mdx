## Keyboard and Pointer Interactions

Focus the full-screen viewport to use keyboard interactions.

- Arrow keys pan the image by [nudgeStep](./#nudgeStep), which defaults to `1` pixel.
- `Shift` with an Arrow key uses [nudgeStepShift](./#nudgeStepShift), which defaults to `10` pixels.
- `Ctrl` or `Cmd` with an Arrow key uses `nudgeStepCtrl`, which defaults to `50` pixels.
- `+` or `=` zooms in.
- `-` or `_` zooms out.
- The mouse wheel zooms around the pointer position.
- Pinch gestures zoom and pan the image on touch devices.
- Press `Escape` or click the backdrop to close the viewer.

Closing resets zoom, rotation, flip, and pan.

## API

### \<ImageViewer>

The simple API accepts the props from [`ImageViewer.Root`](./#image-viewer-root) except `children`. It renders the preview, popup, zoom controls, and reset control. Use the composite API for custom popup contents.

## Shortcuts

### \<ImageViewer.FloatingPortal>

`ImageViewer.FloatingPortal` combines the portal, backdrop, positioner, and content elements.

```tsx
import {Portal} from "@qualcomm-ui/react-core/portal"

;<Portal {...props}>
  <ImageViewer.Backdrop {...backdropProps} />
  <ImageViewer.Positioner {...positionerProps}>
    <ImageViewer.Content {...contentProps}>{children}</ImageViewer.Content>
  </ImageViewer.Positioner>
</Portal>
```

## Overview

The image viewport uses the full available width and a 16:9 aspect ratio by default. The image fills the viewport.

## Keyboard and Pointer Interactions

Focus the viewport to use keyboard interactions.

- Arrow keys pan the image by [nudgeStep](./#nudgeStep), which defaults to `1` pixel.
- `Shift` with an Arrow key uses [nudgeStepShift](./#nudgeStepShift), which defaults to `10` pixels.
- `Ctrl` or `Cmd` with an Arrow key uses `nudgeStepCtrl`, which defaults to `50` pixels.
- `+` or `=` zooms in.
- `-` or `_` zooms out.
- The mouse wheel zooms around the pointer position.
- Pinch gestures zoom and pan the image on touch devices.

## Viewport Sizing

Set the viewport `style` to override the default 16:9 dimensions.

```tsx
<ImageViewer.Root className="w-full">
  <ImageViewer.Viewport
    style={{aspectRatio: "4 / 3", maxWidth: "48rem"}}
  >
    <ImageViewer.Image
      alt="Earth at night viewed from space"
      src="/images/connected-l.png"
    />
  </ImageViewer.Viewport>
</ImageViewer.Root>
```

## Overview

The simple API renders the image, viewport, and default zoom out, zoom in, and reset controls. Set `controls` to `false` when the controls are rendered elsewhere.

The composite API exposes the root, viewport, image, context, root provider, and control button components. Use it when the controls or layout require custom placement.

The QDS viewport uses the full available width and a 16:9 aspect ratio by default. The image fills the viewport.

## Keyboard and Pointer Interactions

Focus the viewport before using keyboard interactions.

- Arrow keys pan the image by `nudgeStep`, which defaults to `1` pixel.
- `Shift` with an Arrow key uses `nudgeStepShift`, which defaults to `10` pixels.
- `Ctrl` or `Cmd` with an Arrow key uses `nudgeStepCtrl`, which defaults to `50` pixels.
- `+` or `=` zooms in.
- `-` or `_` zooms out.
- The mouse wheel zooms around the pointer position.
- Pinch gestures zoom and pan the image on touch devices.

## Viewport Sizing

Use `viewportProps` to override the default 16:9 viewport dimensions.

```tsx
<ImageViewer
  alt="Earth at night viewed from space"
  src="/images/connected-l.png"
  viewportProps={{
    style: {aspectRatio: "4 / 3", maxWidth: "48rem"},
  }}
/>
```

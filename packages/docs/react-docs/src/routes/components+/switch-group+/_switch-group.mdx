## Examples

### Simple

Use the simple API to create a switch group using minimal markup.

If you omit the [label](./#label), you should provide an `aria-label` prop to keep your group accessible.

<Demo name="SwitchGroupSimpleDemo" component={demos.SwitchGroupSimpleDemo} />

<Demo
  name="SwitchGroupCompositeDemo"

/>

### Size

::: terms
small
medium
large
:::

The [size](./#size-1) prop controls the size of child switches. Available sizes are `sm`, `md` (default), and `lg`.

<Demo name="SwitchGroupSizeDemo" component={demos.SwitchGroupSizeDemo} />

### Orientation

::: terms
vertical
horizontal
row
column
:::

Use the [orientation](./#orientation-1) prop to control the layout direction of the group. Options include:

- `vertical`: switches are laid out in a column (default).
- `horizontal`: switches are laid out in a row.

<Demo
  name="SwitchGroupOrientationDemo"
  component={demos.SwitchGroupOrientationDemo}
/>

### Indented

Set [indented](./#indented-1) to add padding at the start of the group.

<Demo
  name="SwitchGroupIndentedDemo"
  component={demos.SwitchGroupIndentedDemo}
/>

### Hint

::: terms
helper text
description
:::

Use [hint](./#hint-1) to add additional guidance or context to the user below the group.

<Demo name="SwitchGroupHintDemo" component={demos.SwitchGroupHintDemo} />

### Error Text

::: terms
validation
invalid
:::

Set [invalid](./#invalid) and [errorText](./#errorText) to display validation errors. The error text replaces the hint when present.

<Demo name="SwitchGroupErrorDemo" component={demos.SwitchGroupErrorDemo} />

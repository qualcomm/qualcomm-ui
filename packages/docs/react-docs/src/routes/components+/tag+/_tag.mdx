### Variants

::: terms
clickable, removable, closable, chip, pill, filter, toggle, anchor, hyperlink, navigation, active, current
:::

A tag renders as one of four types:

- **read-only** (default) renders static metadata.
- **dismissable** adds a close button. Set [variant](./#variant) to `dismissable` and pair it with the dismiss callback.
- **selectable** renders as a toggle `<button>`. Set [variant](./#variant) to `selectable`.
- **link** renders the tag as an anchor. Use the [render](./#render) prop to supply `<Link to="…" />` or `<a href="…" />`. Set [`aria-current`](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-current) on the active anchor for accessibility. The optional [active](./#active) prop applies the current-item styling.

## Examples

### Linear Mode

The stepper is linear by default ([linear](./#linear) is `true`). Steps must be completed in order.

- Backward navigation is always allowed
- Previously visited steps can be re-clicked without restriction
- Forward navigation is restricted to the immediate next step
- [canGoToStep](./#canGoToStep) can override forward navigation decisions

<Demo component={demos.StepperLinearDemo} name="StepperLinearDemo" />

### Non-linear Mode

Set [linear](./#linear) to `false` to allow accessing any step at any time. Use the [completed](./#completed) prop to manually track which steps are done.

[canGoToStep](./#canGoToStep) applies to all navigation if provided. Otherwise, all navigation is allowed.

<Demo component={demos.StepperNonlinearDemo} name="StepperNonLinearDemo" />

### Layout & Orientation

Stepper orientation and label placement are controlled through the [orientation](./#orientation) prop.

#### Horizontal

`horizontal` (default): The step list is centered horizontally, and the labels are stacked vertically and centered below the step indicator.

<Demo component={demos.StepperHorizontalDemo} name="StepperHorizontalDemo" />

#### Horizontal Inline

`horizontal-inline` is a variant of `horizontal` that places the step indicator and labels inline. The step items are left-aligned and take the full width of their parent container

<Demo
  component={demos.StepperHorizontalInlineDemo}
  name="StepperHorizontalInlineDemo"
/>

#### Horizontal Bottom Start

`horizontal-bottom-start` is a variant of `horizontal` that places the labels below each step, aligned to the start. The items are left-aligned and take the full width of their parent container.

<Demo
  component={demos.StepperHorizontalBottomStartDemo}
  name="StepperHorizontalBottomStartDemo"
/>

#### Vertical

Set [orientation](./#orientation) to `vertical` to stack the steps vertically. The labels are centered relative to the step indicator.

<Demo name="StepperVerticalDemo" component={demos.StepperVerticalDemo} />

#### Vertical Inline

Set [orientation](./#orientation) to `vertical-inline` to stack the steps vertically while aligning the labels inline with the step indicator.

<Demo
  name="StepperVerticalInlineDemo"
  component={demos.StepperVerticalInlineDemo}
/>

Use the [pending](./#pending) prop to mark steps as pending. This is typically used to indicate that a step has been visited but not completed.

<Demo component={demos.StepperPendingDemo} name="StepperPendingDemo" />

The stepper comes in two [sizes](./#size): `sm` and `lg`. The default size is `lg`.

<Demo expanded name="StepperSizesDemo" component={demos.StepperSizesDemo} />

### Validation Examples

#### Non-linear Form

Combine `linear={false}` with per-step validation to let users complete steps in any order. Use the [invalid](./#invalid) and [completed](./#completed) props to track each step's status, and [Stepper.Context](./#stepper-context) to conditionally render a submit action once all steps pass.

  name="StepperNonlinearFormDemo"
  component={demos.StepperNonlinearFormDemo}
/>

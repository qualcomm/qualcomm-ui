### Emphasis

::: meta
keywords: [severity, notification type, error banner, success banner, alert level]
:::

The [emphasis](./#emphasis-1) prop controls the banner's color scheme. The default is `info`. Each emphasis also determines the default icon.

<Demo
  name="AlertBannerEmphasisDemo"
  component={demos.AlertBannerEmphasisDemo}
/>

### Variant

::: meta
keywords: [strong banner, subtle banner, banner style, visual weight]
:::

The [variant](./#variant-1) prop controls visual prominence. The default `strong` variant uses solid backgrounds for high visibility. The `subtle` variant uses muted backgrounds with borders.

<Demo name="AlertBannerVariantDemo" component={demos.AlertBannerVariantDemo} />

### Dismissable

::: meta
keywords: [closeable, close banner, remove banner, hide banner]
:::

The banner is a controlled component. Set [dismissable](./#dismissable-1) to render a close button, then handle visibility state via the [onClose](./#onClose) callback. With the composite API, use [`<AlertBanner.CloseButton />`](./#alert-banner-close-button).

<Demo
  name="AlertBannerDismissableDemo"
  component={demos.AlertBannerDismissableDemo}
/>

### Action

::: meta
keywords: [banner button, banner cta, call to action]
:::

Pass a button to the [action](./#action-1) prop. Use `size="sm"` with `emphasis="white-persistent"` for strong banners, or `emphasis="neutral"` for subtle banners.

<Demo name="AlertBannerActionDemo" component={demos.AlertBannerActionDemo} />

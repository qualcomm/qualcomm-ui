## Examples

### Variants

::: terms
solid button
bordered button
transparent button
:::

Buttons come in three variants: `fill`, `outline`, and `ghost`. Customize these with the [variant](./#variant) property.

<Demo name="ButtonShowcaseDemo" component={demos.ButtonShowcaseDemo} />

### Emphasis

::: terms
destructive button
delete button
:::

Control the visual [emphasis](./#emphasis) with different colors: `neutral`, `primary`, and `danger`.

<Demo name="ButtonEmphasisDemo" component={demos.ButtonEmphasisDemo} />

### Sizes and Icons

::: terms
small
medium
large
:::

Control dimensions with the [size](./#size) prop. Icons are supplied using the [startIcon](./#startIcon) and [endIcon](./#endIcon) props.

<Demo name="ButtonSizesDemo" component={demos.ButtonSizesDemo} />

### Compact Density

::: terms
condensed button
slim button
tight button
:::

Use the [density](./#density) prop to reduce the padding and height of the button. The options are `default` and `compact`.

<Demo name="ButtonDensityDemo" component={demos.ButtonDensityDemo} />

### Variant Combinations

::: terms
button grid
button matrix
all button styles
:::

This grid shows all button combinations across variants and emphasis levels. The bottom row demonstrates the disabled state, which grays out the button regardless of variant or emphasis.

<Demo name="ButtonVariantsDemo" component={demos.ButtonVariantsDemo} />

### Contrast Colors

::: terms
high contrast button
button on dark background
inverted button
:::

Use `white-persistent` for buttons on dark backgrounds and `black-persistent` for buttons on light backgrounds. These emphasis values maintain consistent contrast regardless of the active theme.

<Demo name="ButtonContrastDemo" component={demos.ButtonContrastDemo} />

### Inverse Contrast

To flip contrast against the active theme, set [emphasis](./#emphasis) to `inverse`.

<Demo component={demos.ButtonInverseDemo} name="ButtonInverseDemo" />

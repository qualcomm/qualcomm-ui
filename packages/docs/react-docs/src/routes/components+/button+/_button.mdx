### Contrast Colors

::: terms

:::

Use `white-persistent` for buttons on dark backgrounds and `black-persistent` for buttons on light backgrounds. These emphasis values maintain consistent contrast regardless of the active theme.

### Badge

::: terms
count badge, notification count, status indicator
:::

Supply a [NumberBadge](/components/badges/number-badge) or [StatusBadge](/components/badges/status-badge) with the [badge](./#badge-1) prop. The badge renders after the label and before the end icon.

The button supplies these defaults: badge size follows the button (`NumberBadge`: `xs` on `sm`/`md`, `sm` on `lg`; `StatusBadge`: `sm` on `sm`/`md`, `md` on `lg`), a disabled button disables its badge, and `NumberBadge` emphasis contrasts with the button. For `outline` and `ghost` buttons, `primary` maps to `brand` and `danger` to `danger`; `StatusBadge` emphasis remains unchanged. Props set on the badge take precedence over these defaults.

The `badge` prop is also available on [Menu.Button](/components/menu#menu-button), and on [Menu.SplitButton](/components/menu#split-button) through `actionProps.badge`.

<Demo name="ButtonBadgeDemo" component={demos.ButtonBadgeDemo} />

### Menu Button

::: terms
menu trigger, dropdown button, icon menu button
:::

For a button that opens a dropdown, use [`Menu.Button`](/components/menu#menu-button) for a labeled trigger or [`Menu.IconButton`](/components/menu#menu-button) for an icon-only trigger.

### Split Button

::: terms
split action, dropdown button, secondary actions
:::

For a button that pairs a primary action with a dropdown of related actions, use [`Menu.SplitButton`](/components/menu#split-button).

## Keyboard Navigation

The DatePicker supports comprehensive keyboard navigation:

- **Arrow Keys**: Navigate between dates in the calendar
- **Enter**: Select the focused date
- **Escape**: Close the calendar
- **Home**: Jump to the start of the current month
- **End**: Jump to the end of the current month
- **Page Up**: Go to the previous month
- **Page Down**: Go to the next month

## Accessibility

The DatePicker follows WAI-ARIA best practices:

- Proper ARIA labels and roles for screen readers
- Keyboard navigation support
- Focus management
- Clear visual indicators for selected, today, and disabled dates

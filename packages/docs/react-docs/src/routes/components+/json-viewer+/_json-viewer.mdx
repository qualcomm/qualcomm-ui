## Examples

### Simple

Pass any JavaScript value to `data`. Use `defaultExpandedDepth` to control how many levels are expanded initially.

### Data Types

The viewer renders values with type-specific coloring for strings, numbers, booleans, null, undefined, dates, regex, and more.

<Demo
  name="JsonViewerDataTypesDemo"
  component={demos.JsonViewerDataTypesDemo}
/>

### Root Provider

Use `useJsonViewer` with `JsonViewer.RootProvider` to control the viewer state externally, such as expanding or collapsing all nodes programmatically.

<Demo
  name="JsonViewerRootProviderDemo"
  component={demos.JsonViewerRootProviderDemo}
/>

### Complex Types

Maps, Sets, Headers, URLSearchParams, URLs, Errors, and functions are all supported.
